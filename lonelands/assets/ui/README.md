# UI skin art

Vendored [Kenney](https://kenney.nl) UI art, released under **CC0 1.0** (public
domain) — free to bundle, no attribution required (given here as courtesy).

| File | Source pack | Use |
|------|-------------|-----|
| `fantasy_border.png` | Fantasy UI Borders → Default/Border | 9-sliced ornamental frame around the HUD panes (`lonelands/skins.py`). White line-art, tinted at draw time. |

The frame is drawn by `lonelands.skins.NineSlice`; see `lonelands/ui.py::UI.hud_panel`.
